# Repository baseline — documentation only

**Current state:** `TND-001` through `TND-006` are `Planned`. This repository only defines the intended application, development workflow, licensing and release verification template.

## Included

- README with user experience, two Mermaid diagrams, technical architecture, license and Ways to Support.
- Brand metadata under `brand/`, including optional empty icon and poster slots.
- `AGENTS.md`, one optional Codex worker, two technology-focused skills and minimal Codex configuration.
- Release 0.1 overview, six stories with acceptance criteria, and honest `Not run` verification.
- Architecture, storage, prediction, editor, privacy, testing and GitHub metadata guides.

## Intentionally absent

- Application source, Electron/Vite/Forge scaffold, preload code, CodeMirror editor plugin.
- `package.json` and lockfile, SQLite schema/migrations, test source, CI workflow.
- Executable build scripts, distributable binaries, screenshots and real performance data.

`TND-001` begins implementation only when explicitly approved. Release completion will require real build, test and packaging evidence. Never imply that Markdown descriptions mean software features already work.
